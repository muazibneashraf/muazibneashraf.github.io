# Website logo assets

Source: the user-supplied Gemini_Generated_Image_7lwwv7lwwv7lwwv7.jpg, preserved as logo-source.jpg in this folder.

Built-in imagegen editing was used for both transparent assets:

- public/brand/logo-wordmark.png — “Extract the complete existing foreground logo: the sculptural M, muaz.dev wordmark and BACKEND & AI DEVELOPER tagline. Preserve the design, letterforms, colors and proportions. Remove the dark background and unrelated corner decorations. Tightly frame on a transparent wide canvas.”
- public/brand/logo-symbol.png — “Extract only the existing sculptural M symbol, preserving its silhouette, gradients and internal network detail. Remove text and background, center it on a transparent square canvas.”

Both PNG files preserve their generated alpha channels. Site & navigation exposes wordmark, compact logo, and browser icon controls. BrandLogo supports both uploaded wordmarks and a compact symbol paired with native website typography.

The user subsequently selected B — Pulse from four angular Neuro-wave concepts generated with the built-in imagegen tool. The active mark is public/brand/neuro-wave-pulse.svg, a crisp geometric M with cyan/blue signal tracks and lilac square terminals. BrandLogo pairs it with native website typography at a compact navigation size; the same mark appears in the admin and browser icon. The earlier SVG and raster extractions are retained as references. Full concept prompts are in concepts/README.md. Transparent extraction attempts introduced unwanted effects and were not used in the website.
